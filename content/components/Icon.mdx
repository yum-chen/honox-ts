# Introduction

A lightweight, size- and color-aware layout wrapper for SVG vector graphics. It enforces uniform visual sizing scales (`2xs`–`xl`) and inherits CSS `currentColor` properties so that graphic icons seamlessly match neighboring text or parent link themes without relying on heavy external third-party font/icon library bundles.

The **Icon** component is fully integrated as an `icon` block in the **Page Builder**, allowing content authors and developers to configure custom SVG paths, coordinate grids, and scales directly within the CMS page schemas.

***

# Usage via CMS Page Builder (JSON)

These examples illustrate how content editors bind and structure custom icon components inside the JSON page schemas (`content/pages/*.json`).

## 1. Standard Layers Vector Icon

Displays a custom vector layer icon with standard size configuration. Ideal for features, lists, and secondary navigation labels.

<DemoPreview>
  <Icon size="lg" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2">
    <path d="M12 2 2 7l10 5 10-5-10-5z" />
    <path d="M2 17l10 5 10-5M2 12l10 5 10-5" />
  </Icon>
</DemoPreview>

```json
{
  "type": "icon",
  "svg": "<path d=\"M12 2 2 7l10 5 10-5-10-5z\" /><path d=\"M2 17l10 5 10-5M2 12l10 5 10-5\" />",
  "viewBox": "0 0 24 24",
  "size": "lg",
  "fill": "none",
  "stroke": "currentColor"
}
```

# CMS Configuration Reference

These fields map directly to Sveltia CMS block properties under `public/admin/config.yml` or the Page Builder configurations:

| Property | CMS Field Type | Default | Description / Supported Options |
| :--- | :--- | :--- | :--- |
| **SVG Markup** (`svg`) | `text` | - | Raw inner vector child XML/path tags, e.g. `<path d="..." />`. |
| **Grid Boundary** (`viewBox`) | `string` | `"0 0 24 24"` | The bounding coordinate system representing the vector bounds. |
| **Fill Brush** (`fill`) | `string` | `"none"` | SVG fill color attribute (e.g. `currentColor`, `none`, hex color, etc.). |
| **Stroke Brush** (`stroke`) | `string` | `"currentColor"` | SVG outline stroke color attribute. |
| **Size Scale** (`size`) | `select` | `"md"` | Controls overall height, width, and bounds bounding box. <br/>• Options: `"2xs"`, `"xs"`, `"sm"`, `"md"`, `"lg"`, `"xl"`. |
| **Accessible Label** (`ariaLabel`) | `string` | - | Descriptive text for assistive technologies. Leave blank for decorative icons. |

# Developer Notes & Accessibility

- **Hydration Free (Static-Only):** The Icon component is a purely presentational vector helper designated as a Static-Only component (`Tier 3`) and operates with zero client-side JavaScript execution.
- **WAI-ARIA Compliance:** Icons are treated as purely decorative visual assets by default (`aria-hidden="true"`). Supplying a custom `ariaLabel` (or `aria-label`) property automatically retains standard accessibility attributes for non-decorative vectors (e.g., standalone icon button links).
